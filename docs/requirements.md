# MVP 요구사항

## 목표

네이버 통합검색이나 기관별 사이트를 반복 방문하지 않고, 서울의 전시·연극·뮤지컬을 날짜·장소·가격으로 빠르게 좁혀 보는 서비스다.

## 범위

- 지역: 서울
- 장르: 전시, 연극, 뮤지컬
- 기간: 오늘 진행 중인 행사부터 3개월 이내 시작/진행 행사
- 출처: 문화포털, KOPIS. 품질 보완이 필요할 때만 서울시 문화행사 API 추가
- 제외: 웹 크롤링, 출처가 불명확한 이미지 재배포, 결제/예매 대행, 추천 알고리즘

## 사용자 흐름

1. 목록에서 검색어와 장르·기간·장소·가격 필터를 조합한다.
2. 오늘/주말/곧 종료 빠른 필터와 종료일/가격/등록일 정렬을 사용한다.
3. 상세에서 일정, 장소, 가격, 출처와 최종 갱신 시각을 확인한다.
4. 관심 표시, 관람 완료와 별점을 남긴다.
5. 목록으로 돌아가면 URL 필터와 `sessionStorage`의 스크롤 위치가 복원된다.

## MVP 완료 기준

- 외부 API 원본을 손실 없이 `raw_events`에 보관하고 정규화한다.
- 동일 행사 후보를 제목·장소·시작일·종료일 기반으로 점수화한다.
- 불확실한 후보는 자동 병합하지 않고 `duplicate_candidates`에 남긴다.
- 공개 검색은 익명 사용 가능, 개인 데이터는 로그인 사용자 자신의 행만 접근 가능하다.
- 외부 키는 FastAPI 환경변수에만 존재하며 브라우저 번들에 포함되지 않는다.
