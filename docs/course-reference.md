# 수업 자료에서 반영한 운영 원칙

참고 위치: `01_BAF60081/3324_final_project` (읽기 전용)

- 공공 API 키는 백엔드 `.env`와 Render 환경변수에만 두고 프론트에 노출하지 않는다.
- KOPIS는 공연 목록 → 공연 상세 → 공연시설 상세 순서로 보강한다.
- 31일 조회 제한에 맞춰 기간을 분할하고, 요청 사이를 약 0.25초 띄우며 일시 차단과 5xx를 재시도한다.
- 저장 전 품질 보고서(dry-run)를 먼저 확인하고, 외부 ID 기반 upsert로 반복 실행을 멱등하게 만든다.
- 일부 출처 실패가 전체 동기화를 중단시키지 않도록 출처별 결과와 오류를 `sync_runs`에 남긴다.
- Render 배포 시 health check, Vercel URL을 포함한 CORS, Asia/Seoul 시간대를 명시한다.
- KOPIS 출처 문구와 원문 링크를 상세 화면에 표시한다.

수업 프로젝트의 코드나 데이터베이스는 복사·수정하지 않고, 위 설계 원칙만 이번 프로젝트에 맞게 재구현한다.
